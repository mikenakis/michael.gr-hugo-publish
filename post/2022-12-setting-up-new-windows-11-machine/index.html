    Instructions for future reference.

    Initial Windows configuration

    • Taskbar:

      • Unpin everything. (File explorer, Microsoft edge, Microsoft Store, "Mail", etc.)

      • Right-click -> Taskbar settings -> Settings / Personalization / Taskbar

        • Search -> Hide
        • Task view -> Off
        • Widgets -> Off
        • Taskbar behaviors
          • Taskbar alignment -> Left
          • Show my taskbar on all displays -> Enable
        • Replace Command Prompt with Windows PowerShell in the menu when I right-click the start button or press Windows logo key + X -> DISABLE
        • Show taskbar buttons on
          • SELECT Main taskbar and taskbar where window is open
        • Show news and interests on the taskbar -> DISABLE

      • This does not work anymore in Windows 11:

        • Open the Run Prompt (with Win+R)
        • Execute this nonsense:
          • explorer shell:::{05d7b0f4-2121-4eff-bf6b-ed3f69b894d9}
        • Always show all icons and notifications on the taskbar -> ENABLE

    • Enable Developer Mode.

    • Set up user environment variables

      • DIRCMD = /OGNE
      • TEMP = %UserProfile%\AppData\Local\Temp
      • TMP = %UserProfile%\AppData\Local\Temp
      • TMPDIR = %UserProfile%\AppData\Local\Temp

    • Kill let's finish setting up your device. (Might be irrelevant in Windows 11)

      • Go to Settings -> System -> Notifications -> Additional Settings
      • Show the Windows welcome experience after updates and when signed in to show what's new and suggested -> DISABLE
      • Suggest ways to get the most out of Windows and finish setting up this device -> DISABLE
      • Get tips and suggestions when using Windows -> DISABLE

    • Disable Windows Error Reporting

      • Open Edit group policy (gpedit.msc)
      • Go to Local computer Policy -> Computer Configuration -> Administrative Templates -> Windows Components -> Windows Error Reporting
      • Set Disable Windows Error Reporting to Enabled.

    • Uninstall crapware:

      • Clipchamp - Video Editor (Windows 11)
      • Cortana (Windows 10)
      • Feedback Hub
      • Mail and Calendar
      • Maps
      • Microsoft News (Windows 11)
      • Microsoft OneDrive
      • Microsoft To Do (Windows 11)
      • Movies & TV
      • Office
      • People (Windows 10)
      • Power Automate (Windows 11)
      • Quick Assist (Windows 11)
      • Solitaire Collection / Microsoft Solitaire Collection
      • Sticky Notes
      • Tips (Windows 11)
      • Weather

    • If the computer has been set-up by an organization:

      • Kill RegisteredOrganization
        • Locate the following registry keys and make sure they are empty:
          • HKLM\Software\Microsoft\Windows NT\CurrentVersion\RegisteredOrganization
          • HKLM\Software\Wow6432Node\Microsoft\Windows NT\CurrentVersion\RegisteredOrganization

    • Unfuck Windows

      • Disable application pinning to taskbar
        • Run gpedit.msc
        • Go to User Configuration -> Administrative Templates -> Start menu and Taskbar
        • Look for Do not allow pinning programs to the Taskbar -> Enable it.
      • Disable fucking up of the Alt+Tab switcher
        • Open windows settings (Win+I)
        • Search for multitasking settings
        • Find Show tabs from apps when snapping or pressing Alt+Tab
          • -> set to Don't show tabs

    • Enable natural mouse wheel scrolling

      • Follow the instructions at Mouse Wheel Natural Scrolling in Windows

    • If dealing with Nazi admins from hell who have taken control over your HOMEDRIVE and HOMEPATH variables and forced them to point to some network drive, thus preventing you from using SSH unless connected to their stupid network:

      • Add the following environment variable:
        • HOME = %UserProfile%

    • Configure Memory Compression

      • In an ELEVATED PowerShell prompt, execute the following:
        • Disable-MMAgent -mc

    • Configure UAC

      • Go to Settings, search for UAC, select User Account Control Settings, set slider to Never notify.
        • Justification: In principle the UAC notification is a good thing to have, but Windows is so fucked up that the UAC notification often starts minimized in the taskbar instead of full screen, so it does not get noticed.

    • Configure 7-Zip

      • Options
        • 7-Zip tab:
          • Icons in context menu -> ENABLE
          • Context menu items:
            • DISABLE ALL, then:
              • Open Archive -> ENABLE
              • Extract to \<Folder> -> ENABLE
              • `Add to <Archive>.zip -> ENABLE

    • Configure Firefox

      • Visit about:config and set browser.tabs.tabMinWidth to 50
      • install Dark Reader extension

      • Add C:\Program Files\Git\usr\bin to the PATH environment variable so that bash is in the path.

    • Configure TortoiseGit

      • Select all defaults, except:
        • English (GB) dictionary -> DISABLE
        • SSH -> SELECT OpenSSH (Alternatively, after installing, go to Options -> Network -> SSH -> SSH client: and enter C:\Windows\System32\OpenSSH\ssh.exe`)
      • Settings -> Colors 1 -> Dark Theme -> ENABLE
      • Select any two files in Windows File Explorer
      • Right-click on the files -> TortoiseGit -> Diff -> File -> Settings -> Colors -> Use dark mode -> ENABLE

    • Configure SysInternals Process Explorer

      • Options
        • Run At Logon -> ENABLE
        • Hide When Minimized` -> ENABLE
        • Allow Only One Instance -> ENABLE
        • Confirm Kill -> DISABLE
        • Tray Icons -> Commit History -> ENABLE

        • Choose a Collection of Settings to Import -> (Browse...)

      • Tools -> Options -> NuGet Package Manager`
        • Click on the camouflaged + button at the top-right corner of the dialog
