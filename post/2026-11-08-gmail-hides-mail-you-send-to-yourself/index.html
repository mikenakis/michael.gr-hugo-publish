    How to make Gmail show you the emails that you send to yourself

    2026-11-08 6 minutes read
    Table of contents
    1. The problem
    2. The solution
    3. How to set it up
    4. What the code does

    Gmail has a nasty habit: if you send an email to yourself, it will not appear in your inbox. It will only appear in your Sent folder, as if you had never received it. Here is how to defeat this behavior using a tiny relay which runs for free on Cloudflare.

    The problem

    Sending an email to yourself is one of the oldest and simplest ways of leaving a note for your future self. You send it, and it shows up in your inbox, unread, staring at you until you deal with it.

    Not with Gmail. Send an email from you@gmail.com to you@gmail.com, and your inbox remains empty. Gmail has decided that you do not need to receive what you have just sent, so the email goes straight to Sent, and it never bothers you again. Which is precisely the opposite of the reason why you sent it.

    You might think that you can outsmart Gmail by taking a detour through another domain. Suppose you own example.org, you have configured me@example.org to forward to you@gmail.com, and you have also configured Gmail to send mail as me@example.org. Now you send an email from Gmail to me@example.org. The email actually leaves Gmail, it travels to the mail servers of your domain, it gets forwarded, and it arrives back at Gmail, and then Gmail makes it disappear anyway. It recognizes the email as one that it has seen before, and files it under Sent, without so much as a trace in your inbox.

    There is no setting for turning this off. Filters do not help either.

    The solution

    If Gmail refuses to deliver an email that it recognizes, then Gmail must be given an email that it does not recognize.

    The solution is a relay: a small program which receives your email, makes a new email with the same content, and sends that new email to your Gmail address. As far as Gmail can tell, the new email comes from somebody else, so it goes in the inbox, like any other email.

    In this example:

    • you@gmail.com is your Gmail address.
    • me@example.org is the address that you send as.
    • relay@example.org is a new address, which exists only for this purpose.

    You send an email to relay@example.org, and it shows up in the inbox of you@gmail.com, with relay@example.org as the sender.

    You will need a domain whose email is handled by Cloudflare Email Routing. Everything else can be done on the Cloudflare web site, under the free plan, with nothing to install on your computer.

    How to set it up

    1. In Cloudflare, go to Email Service | Email Routing | Destination addresses and make sure that you@gmail.com is listed as verified.
    2. Go to Workers & Pages, create an application, choose Start with Hello World!, give it a name, and click Deploy.
    3. In the settings of the new Worker, under Bindings, click Add binding, choose Email Service, and name the variable EMAIL.
    4. Click Edit code, replace all of the code with the code below, changing the addresses at the top to your own, and click Deploy.
    5. Go to Email Service | Email Routing | Routing rules and create a routing rule which sends relay@example.org to your Worker. Your existing rules and your catch-all can stay exactly as they are.
    6. Wait a few minutes, because the new rule does not take effect immediately, and then send an email to relay@example.org.
    7. Within a minute or two, the email should arrive in the inbox of you@gmail.com, with relay@example.org as the sender.

    Here is the code:

    import { EmailMessage } from "cloudflare:email";

const relayAddress = "relay@example.org";
const destinationAddress = "you@gmail.com";
const allowedSenderSet = new Set( [ "me@example.org", "you@gmail.com" ] );
const copiedHeaderNameSet = new Set( [ "subject", "date", "mime-version", "content-type", "content-transfer-encoding" ] );

const lineBreak = "\r\n";
const headerSectionTerminator = new TextEncoder().encode( lineBreak + lineBreak );

function addressFromHeaderValue( headerValue )
{
	const angleBracketMatch = headerValue.match( /<([^>]+)>/ );
	const address = angleBracketMatch === null ? headerValue : angleBracketMatch[1];
	return address.trim().toLowerCase();
}

function headerSectionLengthFromBytes( messageBytes )
{
	for( let index = 0; index <= messageBytes.length - headerSectionTerminator.length; index++ )
		if( headerSectionTerminator.every( ( byte, offset ) => messageBytes[index + offset] === byte ) )
			return index;
	throw new Error( "The message has no end of headers." );
}

function headerLineArrayFromText( headerSectionText )
{
	return headerSectionText.split( /\r\n(?![ \t])/ );
}

function relayedBytesFromOriginalBytes( originalBytes, originalFromHeaderValue )
{
	const headerSectionLength = headerSectionLengthFromBytes( originalBytes );
	const headerSectionText = new TextDecoder().decode( originalBytes.subarray( 0, headerSectionLength ) );
	const copiedHeaderLineArray = headerLineArrayFromText( headerSectionText )
		.filter( line => copiedHeaderNameSet.has( line.substring( 0, line.indexOf( ":" ) ).trim().toLowerCase() ) );
	const newHeaderLineArray = [
		`From: ${relayAddress}`,
		`To: ${destinationAddress}`,
		`Reply-To: ${originalFromHeaderValue}`,
		`Message-ID: <${crypto.randomUUID()}@example.org>`,
		...copiedHeaderLineArray
	];
	const newHeaderBytes = new TextEncoder().encode( newHeaderLineArray.join( lineBreak ) );
	const bodyBytes = originalBytes.subarray( headerSectionLength );
	const relayedBytes = new Uint8Array( newHeaderBytes.length + bodyBytes.length );
	relayedBytes.set( newHeaderBytes, 0 );
	relayedBytes.set( bodyBytes, newHeaderBytes.length );
	return relayedBytes;
}

export default {
	async email( message, environment )
	{
		const originalFromHeaderValue = message.headers.get( "from" ) ?? "";
		const headerSender = addressFromHeaderValue( originalFromHeaderValue );
		const envelopeSender = message.from.toLowerCase();

		if( !allowedSenderSet.has( envelopeSender ) && !allowedSenderSet.has( headerSender ) )
		{
			message.setReject( "This address accepts mail only from its owner." );
			return;
		}

		const originalBytes = new Uint8Array( await new Response( message.raw ).arrayBuffer() );
		const relayedBytes = relayedBytesFromOriginalBytes( originalBytes, originalFromHeaderValue );
		const relayedStream = new Response( relayedBytes ).body;
		const relayedMessage = new EmailMessage( relayAddress, destinationAddress, relayedStream );
		await environment.EMAIL.send( relayedMessage );
	}
};

    What the code does

    • It refuses any email that does not come from one of the addresses in allowedSenderSet, because otherwise anyone who discovers the relay address could use it to put things in your inbox.
    • It gives the new email a new Message-ID, a new From, and a new To, and it copies only the subject, the date, and the headers that describe the content. Everything else is left out, including In-Reply-To, References, and the signatures of the original email, so that Gmail is given nothing by which to recognize it.
    • It places the original sender in Reply-To, so that the original sender is not lost.
    • It copies the body byte by byte, without parsing it. Thus, formatting and attachments arrive intact, no library is needed, and the code should stay within the 10 milliseconds of CPU time that the free plan of Cloudflare Workers allows, even when the attachments are large.

    The only thing you need to remember is to address those emails to relay@example.org instead of to yourself. It is a small price to pay for getting your own mail delivered to you.
